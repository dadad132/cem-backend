MeshCentral Server Checklist

  1. Enable iframe embedding & login tokens in your MeshCentral meshcentral-data/config.json: 
    {
  "settings": {
    "allowFraming": true,
    "allowLoginToken": true
  }
}
  2. Generate your Login Token Key on the MeshCentral server: 
    node node_modules/meshcentral --loginTokenKey
    Paste the output into the Login Token Key field on the left.
  3. Restart MeshCentral, click Save, then click Test Connection and Sync Devices on the Remote Dashboard.
  4. Install the MeshAgent on client PCs from your MeshCentral group page — once installed, they automatically appear in this dashboard!
