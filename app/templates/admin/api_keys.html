API Quick-Start

Add this header to every request from the other program:

X-API-Key: cem_your_key_here

Common endpoints

  • GET /api/v1/me
  • GET /api/v1/tickets?updated_since=...&include=comments,history
  • POST /api/v1/tickets (including external_ref)
  • PATCH /api/v1/tickets/{ticket_number} (status, priority, closing_notes, close_type, billing fields, external_ref)
  • POST /api/v1/tickets/{ticket_number}/comments

Outbound webhook headers

X-CEM-Event: ticket.created X-CEM-Timestamp: 2026-01-01T12:00:00Z X-CEM-Signature: sha256=…

Verify the signature with timestamp + "." + raw body using the webhook secret shown when you saved the key.
