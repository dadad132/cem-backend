How company backups work

  • • A backup holds only this company's data — tickets, comments, tasks, projects, users, knowledge base, settings and attachments

⚠️

Before you restore

  • • Restoring replaces this company's tickets, tasks, users and attachments with the backup's contents
  • • Anything this company added after the backup was taken will be lost
  • • A safety backup of the current state is taken first, so you can roll the restore back
  • • User accounts are replaced, so everyone in this company will need to sign in again
  • • Other companies on this server are not affected in any way
💡

Disaster Recovery Workflow

  1. Regular backups: Download backups to your own machine on a schedule
  2. If data is lost: Upload your most recent backup file using the form above
  3. Restore: Click restore on the uploaded backup
  4. Result: This company's records and attachments return to the backup's state
